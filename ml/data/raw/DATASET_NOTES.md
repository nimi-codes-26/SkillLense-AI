# Dataset Notes — student_data.csv

## This dataset is synthetic, not real student data

`student_data.csv` was generated by [`ml/generate_synthetic_data.py`](../../generate_synthetic_data.py),
not collected from real students. This is a deliberate, documented limitation of the
current project stage, not something hidden or disguised as real data.

## How it was generated

1. Five rough "student archetypes" were defined by hand (e.g., "high all-round
   performer", "developing student"), each with approximate typical values for the
   9 skill features.
2. Each of the 300 synthetic students was randomly assigned one archetype, then their
   actual feature values were sampled from a normal distribution centered on that
   archetype's values, with random noise added (standard deviation 1.2).
3. Values were clipped to valid ranges (0-10 for skill scores, small non-negative
   integers for counts) and rounded to look like realistic scores.

This means the dataset has overlapping, noisy groups rather than perfectly clean,
separable ones — similar to what real student data would look like — but it is still
an approximation based on hand-picked archetype values, not real-world observation.

## Columns

| Column | Range | Description |
|---|---|---|
| student_id | 1–300 | Synthetic identifier |
| cgpa | 0–10 | Academic performance |
| coding_skill | 0–10 | Programming ability |
| dsa_skill | 0–10 | Data structures & algorithms ability |
| math_aptitude | 0–10 | Quantitative / logical reasoning |
| communication_skill | 0–10 | Soft skills |
| security_knowledge | 0–10 | Networking / security fundamentals |
| projects_count | 0–10 | Number of completed projects |
| internships_count | 0–5 | Number of internships |
| certifications_count | 0–5 | Relevant certifications |

## Important: `generation_reference.csv`

A second file, `generation_reference.csv`, records which archetype was used to
generate each student (by `student_id`). This exists **only** so that, later, we can
sanity-check whether the skill categories discovered by K-Means clustering roughly
resemble these archetypes (a reasonableness check, not proof of correctness).

**This reference file must never be joined into the training data or used as a
feature or target.** Doing so would defeat the entire point of discovering skill
categories from the data with K-Means — the classifier is meant to learn from
genuinely unlabeled data, not from a hidden answer key.

## Limitations

- Archetype mean values were chosen by reasoning, not measured from real students.
- Feature correlations only exist to the extent the archetypes encode them (e.g.,
  higher coding_skill roughly correlating with higher dsa_skill); subtler real-world
  correlations are not captured.
- Sample size (300) is small and evenly-ish spread across archetypes by construction,
  which may not reflect a real cohort's actual distribution.
- This dataset should be replaced with real, anonymized student survey data if
  practical, using the exact same column names and ranges so no downstream code needs
  to change.
